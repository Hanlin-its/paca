# 更新 v0.20.3 原始碼並保留繁中與 MinIO

狀態：使用者已核准 A 方案及翻譯用詞；程式碼整合、隔離驗證、獨立審查及新分支同步完成。本次未部署正式服務。

## 背景與證據

- 本地基準為 v0.18.4 繁中版 `3443b075af02730e0941df08b3bf43b56d0d2d63`。
- GitHub 最新穩定 release 查核日期為 2026-11-13；選定 v0.20.3，固定 commit `82adbac29897cb729f6a2e58971b2a57d0055a1f`，發布日期 2026-11-09。
- 上游累積變更 1,395 個檔案：779 修改、577 新增、37 移除、2 搬移。使用者已審閱並確認範圍。
- 暫存合併無文字衝突；原 16 個本地自訂檔案不與上游變更重疊。
- 新增 19 個 migration，涉及 IAM 角色、帳號整併、公開專案取消、Git 整合及登入安全。
- 本機正式服務維持 0.18.4，自建繁中 Web 與 MinIO 使用既有部署設定。

## 方案與取捨

1. 更新程式碼、補齊繁中、完成隔離驗證後同步 fork：可交付可審閱的版本，正式環境不承受本次資料遷移及中斷；新版功能須另行部署後才生效。
2. 同時部署：可立即使用新版功能，但需停寫、最終備份、Valkey 認證設定及不可逆 schema 遷移，影響正式環境。

使用者選擇方案 1。建立 `codex/upgrade-v0.20.3-zh-tw`，保留舊分支，不合併 fork master，不向官方提出 PR。

## 繁中與本地差異

- 新增 844 個文案鍵，調整 5 個既有文案，沿用 zh-TW 註冊及語言切換測試。
- 49 個停用鍵移至 `docs/localization/zh-TW-v0.18-legacy.json`，原 v0.8 封存保留。
- 使用者指定 Token、存取權Token、合併請求(MR)，現行介面的既有 Token 文案一併統一。
- 保留 `deploy/docker-compose.minio.yml`，不切換 RustFS，不改正式 `.env.local`。

## 風險與緩解

- IAM 遷移不轉換舊受限 Agent／環境的個別授權；公開專案匿名存取取消。唯讀盤點當下，未刪除的公開專案、Agent、環境均為 0；仍需核對角色映射，不以零筆數宣稱授權等價。
- 帳號欄位整併後會移除舊欄位及孤兒角色關聯；只在正式資料的隔離備份副本演練，不能把結果視為正式遷移已完成。
- 新版 API 啟動會自動遷移；API、runner、realtime 必須在未來部署時協調切換。舊映像不能直接連線到已升級 schema 當作回滾。
- 內建 Valkey 新增密碼要求。正式設定目前未提供該密碼，本次只以假值檢查設定，未來部署必須另行配置。
- API 分頁、角色指派與 Agent 金鑰規格變更。外部自訂呼叫端尚未列入實際端對端驗證，不宣稱全部相容。
- 備份包含資料與秘密值，保存在忽略版本控制的目錄，限制目錄及檔案權限，不推送 GitHub。

## 回滾策略

本次正式服務沒有切換。程式碼可使用保留的 v0.18.4 分支／commit；依賴需依對應 lockfile 安裝。隔離測試副本不回寫正式資料庫。若未來選擇正式部署，需另製作最新備份並確認部署及還原範圍。
