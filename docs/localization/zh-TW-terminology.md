# 繁體中文術語

v0.20.3 升級採用使用者確認的翻譯提案，以下三項為使用者指定寫法：

| 英文 | 繁中介面寫法 |
|---|---|
| Token | Token |
| Access token | 存取權Token |
| Merge request | 合併請求(MR) |

其他主要術語：

| 英文 | 繁中介面寫法 |
|---|---|
| Account | 帳號 |
| Service account | 服務帳號 |
| Agent | AI Agent |
| Workspace | 工作區 |
| Identity | 身分 |
| Provider | 提供者 |
| Role / Policy / Statement | 角色／政策／陳述式 |
| Permission | 權限 |
| Action（IAM） | 操作 |
| Action（自動化） | 動作 |
| Allow / Deny | 允許／拒絕 |
| Full access | 完整存取權 |
| Assign roles | 指派角色 |
| Passkey | 通行金鑰 |
| Authenticator app | 驗證器應用程式 |
| Recovery code | 復原碼 |
| Two-step verification | 兩步驟驗證 |
| Multi-factor authentication | 多因素驗證 |
| API key / Revoke key | API 金鑰／撤銷金鑰 |
| Repository / Branch / Commit | 儲存庫／分支／提交 |
| Pull request | 提取請求（PR） |
| Change request | 變更請求 |
| Connection | 連線 |
| Webhook | Webhook |
| Reasoning effort | 推理強度 |
| Automation / Trigger | 自動化／觸發條件 |
| Subtask / Comment / Dynamic value | 子任務／留言／動態值 |

保留插值參數、CLI／API 識別字、品牌與模型名稱。歷史翻譯封存保留當時文字，不隨現行術語改寫。

日期條件提示依實際選項使用 `less_than（早於）`；目標版英文原文稱為 `before`，介面顯示的運算子代碼為 `less_than`，其日期判斷為 `field.Before(target)`。此調整只修正文案，不改變判斷邏輯。
